# Careers Page Frontend

Scaffolded Vite + React + TypeScript frontend for the Careers Page.

Prereqs: Node 18+ (or compatible), npm/yarn.

Run:

1. Copy `.env.example` to `.env` and set `VITE_API_BASE_URL`.
2. npm install
3. npm run dev

Tests: `npm test` (Vitest)

This project expects the backend API at `${VITE_API_BASE_URL}/api/v1/jobs` with the exact contract described in the repository documentation.
